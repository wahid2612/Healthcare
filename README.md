# Healthcare
This project involves comprehensive analysis of a healthcare database using pure MySQL queries. It answers 25 real-world questions related to patient demographics, medical conditions, doctor assignments, hospital admissions, and billing.

### 🧑‍⚕️ Patient Demographics
- Retrieve names and details of **all patients**.
- List **unique medical conditions** present in the dataset.
- Count patients by **gender** (male/female) and **age** (e.g., patients older than 60 years).
- List names of patients whose **name starts with 'A'**.

### 🏥 Medical Conditions & Treatments
- Identify the **most common medical conditions** among patients.
- Find patients who have **multiple medical conditions**.
- List patients with specific conditions like **Asthma**, **Cancer**, **Diabetes**, etc.
- Identify patients whose **age is greater than average age** and who have specific conditions.

### 🩺 Doctors & Hospital Admissions
- Find the **total number of doctors** in the system.
- List all **doctor names**.
- Identify the **doctor treating the oldest patient**.
- Determine the **average duration of medical visits**.
- Retrieve details of patients admitted to a specific room (e.g., Room No. 292).

### 💰 Financial Data
- Calculate the **total revenue generated** by the healthcare system.
- Find patients who have **paid bills above a specific amount** (e.g., above $24,890).
- List **patients with cancer** and their financial details.

### 🏨 Insurance & Provider Information
- List patients who are covered by a particular **insurance provider** (e.g., Cigna).
- Determine the number of patients admitted to **specific hospitals** (e.g., Harris and Sons).

## 🛠 Technologies Used

- **MySQL**: All data extraction and analysis have been performed using **MySQL** queries.
- **MySQL Workbench / Command Line**: These tools were used to run queries and analyze the database.


📌 Summary
This project demonstrates how to analyze healthcare data using MySQL, focusing on extracting useful insights like patient demographics, medical conditions, doctor-patient relationships, hospital admissions, and financial transactions. The queries can be used by healthcare analysts, data scientists, or anyone interested in understanding complex healthcare data.
